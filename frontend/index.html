Tu circuito, conectado

Una sesión compartida en web y móvil

ESP32DHT11→JavaSQLite→WebPC / celular
Conectar el ESP32
  1. Configura el Wi-Fi en ESP32_Telemetria.ino.
  2. En UDP, cambia PC_IP por la IPv4 de esta computadora y activa DIP 1 (ON / LOW).
  3. En TCP, coloca DIP 1 en OFF (HIGH) e introduce aquí la IP que aparece en la OLED.
  4. Inicia el modo correspondiente. Cierra la aplicación Swing si ocupa el puerto UDP.
Abrir en el celular

Conecta el celular al mismo Wi-Fi y abre http://IP_DE_LA_PC:3000. La consola de Java muestra la dirección. Permite Java en redes privadas si Windows solicita acceso.

Si reinicias el ESP32, detén e inicia una nueva sesión. El sensor conserva su última lectura cuando falla; la web indica si no llegan muestras nuevas.
